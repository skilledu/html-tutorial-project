HTML – OVERVIEW

  1. HTML stands for Hypertext Markup Language, and it is the most widely used language to write Web Pages.
  • Hypertext refers to the way in which Web pages (HTML documents) are linked together. Thus, the link available on a webpage is called Hypertext.
  • As its name suggests, HTML is a Markup Language which means you use HTML to simply "mark-up" a text document with tags that tell a Web browser how to structure it to display. Originally, HTML was developed with the intent of defining the structure of documents like headings, paragraphs, lists, and so forth to facilitate the sharing of scientific information between researchers. Now, HTML is being widely used to format web pages with the help of different tags available in HTML language. Basic HTML Document In its simplest form, following is an example of an HTML document:
Example Code 
<!DOCTYPE html>
<html>
<head>
<title>This is document title</title>
</head>
<body>
<h1>This is a heading</h1>
<p>Document content goes here.....</p>
</body>
</html>

The <!DOCTYPE> Declaration

The <!DOCTYPE> declaration tag is used by the web browser to understand the version of the HTML used in the document. Current version of HTML is 5 and it makes use of the following declaration:

Common Mistakes

  • Forgetting the DOCTYPE declaration — Omitting <!DOCTYPE html> forces browsers into "quirks mode", causing unpredictable rendering issues.
  • Missing closing tags — Forgetting to close tags like </html> or </body> can break the document tree structure.
  • Placing visible content in the <head> — The <head> section is for metadata. Visible elements like text or images must go inside the <body>.
  • Incorrect nesting of tags — Opening a tag inside another but closing it outside (e.g., <p><strong>text</p></strong>) leads to invalid HTML.

Best Practices

  • Always include a DOCTYPE — Start every HTML document with <!DOCTYPE html> to ensure standard mode rendering.
  • Use lowercase for tag names — Although HTML5 is case-insensitive, using lowercase (e.g., <body> instead of <BODY>) is standard practice and easier to read.
  • Indent nested elements — Properly indent child elements to make the HTML structure readable and maintainable.
  • Include a <title> tag — Always specify a title inside the <head> for SEO and browser tab identification.

Interview Questions

Q: What does HTML stand for and what is its primary purpose?

A: HTML stands for HyperText Markup Language. Its primary purpose is to define the structure and content of a web page using markup tags.

Q: What is the purpose of the <!DOCTYPE html> declaration?

A: It instructs the web browser about the version of HTML the page is written in (HTML5 in this case) and ensures the browser renders the page in "standards mode" rather than "quirks mode".

Q: Differentiate between the <head> and <body> tags.

A: The <head> element contains metadata, title, and links to external resources like CSS or scripts. It is not displayed on the page. The <body> element contains all the visible content of the webpage, such as headings, paragraphs, and images.

Q: Is HTML a programming language?

A: No, HTML is not a programming language because it does not have logic, loops, or variables. It is a markup language used purely for structuring content.

Q: What happens if you forget to close an HTML tag?

A: While modern browsers try to auto-correct missing closing tags, it can lead to unexpected rendering, layout breakage, and invalid DOM structures.

Summary

HTML is the foundational building block of the web, used to define the structure of web pages. A standard HTML document requires a DOCTYPE, an <html> root element, a <head> for metadata, and a <body> for visible content. Understanding this basic skeleton is crucial before moving on to more complex tags and attributes.
